# Home Loan & LVR Calculator

A single-page calculator for exploring home loan scenarios. Adjust the deposit, purchase price, and fees to see how your loan-to-value ratio (LVR) is calculated, with stamp duty and other fees kept separate so they don't distort the LVR figure. Includes a cost breakdown (cash contribution, loan amount, fees) and a structured loan repayment view.

**Live demo:** https://stephenfreely.github.io/loan-calculator/

## Usage

The entire app is a single `index.html` file with no build step or dependencies — just open it in a browser, or visit the live demo above.
